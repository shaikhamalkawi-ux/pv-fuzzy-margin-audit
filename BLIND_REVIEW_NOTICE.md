# Blind-review notice

This repository is public at the author's request, but it is **not cited in the current blind manuscript**.

During blind review:
- do not add author names, affiliations, ORCID identifiers, or manuscript PDF files here;
- do not add a CITATION.cff with identifying author metadata;
- do not link this repository from the blind manuscript;
- do not tag a release with a manuscript title that would unnecessarily increase discoverability.

After acceptance, the repository can be converted into the archival public release and linked to the paper/DOI.

The repository owner identity is inherently visible on GitHub. Therefore a reviewer who independently discovers this repository could potentially infer authorship even though the manuscript does not link to it.
